───────────────────────────────────────────────────────────────────────────
WAY 1 — FRESH START (recommended, 10 minutes, use this for the demo)
───────────────────────────────────────────────────────────────────────────
1. Extract this zip into a NEW empty folder, e.g.  C:\sheggar-wheels
2. Open a terminal IN that folder.
3. Install dependencies (needs Node.js 20+):
       npm install
4. Create your environment file:
       cp .env.example .env        (Windows: copy .env.example .env)
   Open .env and set DATABASE_URL to your Postgres
   (Supabase: Settings → Database → Connection string → URI)
   and set SESSION_SECRET to any long random text.
5. Create the database tables + demo data:
       npx prisma db push
       npm run db:seed
6. Run it:
       npm run dev
   → open http://localhost:3000  (sign in: yonas@sheggarwheels.et /
   Sheggar!2026 — the sign-in page also lists every demo account)

───────────────────────────────────────────────────────────────────────────
WAY 2 — COPY-PASTE INTO YOUR EXISTING PROJECT
───────────────────────────────────────────────────────────────────────────
If you already have a working project folder and just want the newest code:

1. Extract this zip. You get folders: src, prisma, public, scripts
   and files: package.json, .env.example, configs, READMEs.
2. Drag EACH folder and EACH file onto your project root (the same
   level as your package.json) and choose "Replace files".
   The important ones:  src  ·  prisma  ·  package.json  ·  .env.example
3. In your project terminal:
       npx prisma db push        (adds the new columns — keeps your data)
       npm run dev               (restart it: Ctrl+C first if running)
4. Hard-refresh the browser:  Ctrl+Shift+R

⚠ Do NOT copy node_modules between machines — always use "npm install".
